# AI Clinical Assistant

An AI-powered clinical assistant that summarizes raw patient notes into concise clinical summaries using LLM fine-tuning.
The project explores **Full Fine-Tuning, LoRA, QLoRA, and DoRA** for healthcare applications.
It includes dataset preparation, preprocessing, fine-tuning, evaluation, and summary generation.
**Gemini 2.5 Flash** is used to explain the trade-offs between different fine-tuning methods.
Built using **Python, PyTorch, Hugging Face, PEFT, and Google Colab**.
